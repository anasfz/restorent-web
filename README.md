# 🍔 Food Lover Restaurant Website

Welcome to the repository for the **"Food Lover"** restaurant website project. This is a front-end web application featuring an attractive and modern design, aimed at showcasing meals, special offers, and opening hours in a professional manner.

🔗 **[Live Demo](https://anasfz.github.io/restorent-web/)**

---

## 📝 Project Description
A landing page for a restaurant called "Food Lover", built using core web technologies (HTML & CSS). The website provides a seamless user experience for visitors to explore the menu, check out special offers, and find contact details and working hours.

## ✨ Features
* **Attractive UI:** Consistent color palette and mouth-watering imagery that reflect the restaurant's vibe.
* **Responsive Design:** Adapts smoothly to different screen sizes.
* **Smooth Navigation:** A sticky navigation bar that allows users to easily jump between different sections of the page.
* **Clear Structure:** Excellent content layout making it easy for visitors to find the information they need.

## 📂 Website Sections
The website is a Single Page Application divided into the following sections:
1. **Home:** A welcoming hero section with a promotional message and a "Book a Table" call-to-action button.
